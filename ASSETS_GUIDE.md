# Free Pixel Art Assets for CYBER OPS

## Asset Sources (All Free & Open Source)

### 1. Character Sprites
**Source:** [Kenney.nl - Top Down Shooter Pack](https://kenney.nl/assets/topdown-shooter)
- Free for commercial use
- Player character sprites
- NPC sprites
- Includes animations

**Alternative:** [OpenGameArt - Sci-Fi Character](https://opengameart.org/content/topdown-scifi-character)

### 2. Tileset & Environment
**Source:** [Kenney.nl - Sci-Fi Pack](https://kenney.nl/assets/space-shooter-redux)
- Walls, floors, tech panels
- Server racks
- Control consoles
- Doors and terminals

**Alternative:** [itch.io - Pixel Art Sci-Fi Tileset](https://0x72.itch.io/16x16-sci-fi-tileset) (Free)

### 3. UI & HUD Elements
**Source:** [Kenney.nl - UI Pack](https://kenney.nl/assets/ui-pack-space-expansion)
- Buttons, panels, progress bars
- Mission tracker frames
- Menu backgrounds

### 4. Effects & Particles
**Source:** [OpenGameArt - Glow Effects](https://opengameart.org/content/glow-effects)
- Terminal glow
- Door lights
- Player aura

## How to Download

```bash
# 1. Visit kenney.nl/assets
# 2. Download these packs:
#    - Top Down Shooter Pack
#    - Space Shooter Redux
#    - UI Pack Space Expansion

# 3. Extract to public/assets/ folder:
public/assets/
├── characters/
│   ├── player.png
│   ├── npc.png
├── tiles/
│   ├── floor.png
│   ├── wall.png
│   ├── door.png
│   ├── terminal.png
├── ui/
│   ├── panel.png
│   ├── button.png
```

## Implementation Steps

1. Download assets from Kenney.nl (100% free, no attribution required)
2. Place in `public/assets/` directories
3. Update sprite paths in SpriteRenderer.ts
4. Build and deploy
